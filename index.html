ARCHITECTURE & SECURITY FLOW

1. Edge & SSL (Ports 80 → 443) Users hit employee.example.com via Internet Gateway. HTTP redirects to HTTPS (Let's Encrypt / Certbot) at the internet-facing ALB across Public Subnets.
2. Compute Tier (AZ1 & AZ2 EC2 + Nginx) ALB Target Group health-checks and routes port 80 traffic to Linux EC2 Nginx instances in AZ1 & AZ2.
3. Data Tier (Private Subnet RDS MySQL) RDS MySQL (:3306) sits inside Private Subnets (AZ1/AZ2 DB Subnet Group) accepting connections strictly from EC2 Security Group.
4. Zero Direct Internet Access (Blocked) Direct Internet → EC2 (:80/:443) and Internet → RDS (:3306) packets are dropped by chained Security Groups.
